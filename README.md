## Das ist nicht der Produktivstand

| | |
|---|---|
| Betriebsmodus | `DEMO` — die Werkzeuge rechnen vollstaendig, verschicken aber nichts |
| Marktdaten | Platzhalter, `geprueft: false` |
| Rechtstexte | Platzhalter, kommen von der Kanzlei |
| Bewertungs-Funnel | `/bewertung.html` bleibt leer, die Instanz laeuft noch nicht |
| Kaeufer-Zaehler | ausgeblendet, weil `gesamt: 0` — die eingebaute Bremse |
| Pfade | mit `/micheal-preview` praefixiert, weil GitHub Pages unter einem Unterverzeichnis ausliefert |

Das Quellprojekt arbeitet mit absoluten Pfaden ab Root und ist unveraendert. Es gehoert nach Netlify, nicht hierher.

`/?statisch` schaltet alle Animationen ab — fuer Screenshots.
